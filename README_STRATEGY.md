# Wedding Roadmap（ウェディングロードマップ）戦略ドキュメント

## プロダクト概要（逆引きPRD）

### ターゲットユーザー
- 結婚を考え始めたカップル（交際段階〜婚約後）
- 入籍・結婚式の準備を体系的に進めたいカップル
- 婚前契約（プレナップ）の確認事項を整理したいカップル
- 国際カップル（日英バイリンガル対応）

### 解決する課題
- 結婚準備は18ヶ月以上にわたる長期プロジェクトだが、全体像が見えにくい
- 「何をいつまでにやるべきか」の優先順位が分からない
- 結婚式費用の見積もりと実費の差が大きく、予算オーバーしやすい
- 婚前の価値観すり合わせ・法的手続きなど、式以外の重要タスクが見落とされがち

### ソリューション
交際中の価値観すり合わせから入籍・新生活まで、結婚の道のり全体を9フェーズのロードマップで管理するアプリ。140以上のプリセットタスク、入籍日からの逆算デッドライン、予算管理、婚前契約チェックリストを搭載。結婚式は任意フェーズとして式なしカップルにも対応。

### コア機能（実装済み）
- **9フェーズロードマップ**: 価値観すり合わせ → プロポーズ・婚約 → 両家対応 → 資金・新居 → 結婚式準備（任意） → 入籍・法的手続き → 引越し → 新生活安定 → ライフプラン
- **140+プリセットタスク**: フェーズ・カテゴリ別に分類、入籍日/結婚式日からの逆算デッドライン自動計算
- **タスク管理**: pending/completed/skipped ステータス、サブタスク、メモ、実費記録
- **予算管理**: カテゴリ別の見積もり範囲（min/max）と実費の比較、全体予算との差分分析
- **婚前契約チェックリスト**: 資産・負債・収入・不動産など30+項目の確認リスト
- **期限管理**: 期限超過タスク検出、直近30日以内の期限タスク表示
- **日英バイリンガル**: タスク名・説明・タイミングの日英切替
- **Supabase連携**: ユーザー認証、タスク/婚前契約/設定のクラウド同期、ゲスト→ログインのデータ移行
- **メール通知**: Resend APIによるメール送信基盤
- **データ移行**: v1→v2のスキーママイグレーション対応

## Stripeマネタイズ戦略

### 現状
**Stripe実装済み**。買い切り¥980のプレミアムプラン。Stripe Checkout + ステータス確認APIによる決済フロー。

### 無料プラン（現行）
- ダッシュボード
- 140+プリセットタスク
- タイムライン管理
- 設定・ゲストモード

### プレミアム機能（現行 ¥980 買い切り）
- 予算管理ページ
- 婚前契約チェックリスト
- データエクスポート/インポート
- クラウド同期（複数端末）

### ペイウォール配置の評価
現在のペイウォール配置は戦略的に優れている:
- **予算管理**: 結婚準備が進むにつれ費用管理の必要性が高まり、ペイウォール到達の自然なタイミング
- **婚前契約**: 法的・財務的に重要な項目のため、有料でも支払う動機が強い
- **クラウド同期**: カップルで共有したいニーズが強く、プレミアムの最大の動機付け
- **タスクは無料**: 140+タスクを無料で使わせることでデータ蓄積を促進し、スイッチングコストを上げる

### 追加ペイウォール候補
- カスタムタスク追加（無料は既存140+タスクのみ）
- 詳細な進捗分析ダッシュボード（フェーズ別完了率グラフ等）
- ゲストリスト管理機能（将来実装時）

### 価格評価
¥980買い切りは適切。結婚準備の総予算（平均350万円〜）に対して¥980は誤差レベル。買い切りにすることで「結婚準備期間だけ使う」ユースケースにも合致。

## リテンション施策

### メール通知トリガー（Resend基盤実装済み）
- 期限超過タスクの通知（「3件のタスクが期限を過ぎています」）
- 今週期限のタスクサマリー（月曜配信）
- フェーズ移行時の祝福＋次フェーズのタスク案内（「フェーズ3完了！次は資金・新居の準備です」）
- 入籍日までのカウントダウン通知（90日前/60日前/30日前/7日前/前日）
- 予算超過アラート（カテゴリ別の実費が見積もり上限を超えた場合）
- 2週間以上タスク更新がない場合のリエンゲージメント

### データ蓄積フック
- 140+タスクの進捗データは完了までの長期間にわたって蓄積される
- 予算データ（見積もり vs 実費）はカテゴリごとに積み上がる
- 婚前契約チェックリストの確認状態はパートナーとの合意の記録
- サブタスクのメモ・ノートは準備過程の詳細な記録として価値がある
- 入籍日設定によりデッドラインが全タスクに波及し、データの一貫性が生まれる

### 習慣形成
- 入籍日までのカウントダウンによる毎日のアプリ起動動機
- フェーズ別の進捗率（%）でゲーミフィケーション効果
- 期限が近いタスクの「今週やること」リストで定期的な確認を促進
- パートナーとの共有利用でお互いのタスク更新が相互の利用を促す

## 不足機能（Quick Wins）

### 1. パートナー招待・共同編集機能
**概要**: 現在のクラウド同期はアカウント単位のため、パートナーが同じデータを編集するには同じアカウントでログインする必要がある。パートナーを招待して2アカウントで同一プランを共同編集できる機能を追加すれば、「二人で結婚準備を進める」という最大の価値提案が本質的に強化される。Supabaseのテーブルにpartner_id列を追加する形で実装可能。

### 2. ゲストリスト管理
**概要**: 結婚式を行うカップルにとって、ゲストリスト（招待者名、関係性、出欠確認、席次、引出物選択）の管理は最も煩雑なタスクの一つ。結婚式フェーズ（phase_05）のタスクと連動するゲストリスト管理機能を追加すれば、結婚式準備のオールインワンツールとしての完成度が大幅に向上する。プレミアム機能として追加ペイウォール対象にも適している。

### 3. ベンダー比較・見積もり管理
**概要**: 結婚式場、カメラマン、フローリスト等のベンダー候補を登録し、見積もりを並べて比較できる機能。calculateCategoryBudgetで予算管理の計算ロジックは実装済みのため、ベンダー単位の見積もり入力UIを追加すれば、予算管理ページの実用性が大幅に向上する。見積書のメモ保存もあると商談時に便利。
